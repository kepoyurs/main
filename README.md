# Client Performance Dashboard

A minimalist, modern dashboard for uploading and displaying screenshots and PDFs of social media, website, and SEO performance statistics to clients.

## Features

- **PDF & Image Support**: Upload full-page PDF screenshots or image files (PNG, JPG, etc.)
- **PDF Rendering**: Automatically renders PDF files for display in the dashboard
- **Drag & Drop Upload**: Easily upload files by dragging them onto the dashboard
- **Click to Upload**: Traditional file upload option available
- **Categorization**: Organize screenshots by type (Social Media, Website Analytics, SEO Performance)
- **Visual Gallery**: Clean, responsive grid layout for displaying performance stats
- **Annotations**: Add titles and descriptions to each screenshot
- **Minimalist Design**: Clean white and gray color scheme for professional presentation
- **Local Storage**: Screenshots are saved in browser storage for persistence

## Getting Started

1. Open `index.html` in your web browser
2. Click "Add Screenshot" or drag and drop image/PDF files onto the upload area
3. Select a category and add optional title/description
4. View your performance dashboard with all uploaded screenshots

## Usage

- **Upload**: Click the "Add Screenshot" button or drag images/PDFs onto the page
- **PDF Support**: Upload full-page PDF reports - they'll be automatically rendered as images
- **Categorize**: Choose from Social Media, Website Analytics, or SEO Performance
- **Annotate**: Add titles and descriptions to provide context
- **View Full-Size**: Click any screenshot to view it in full-screen mode
- **Delete**: Remove screenshots you no longer need
- **Filter**: Use the dropdown to show only specific categories
- **Clear All**: Reset the dashboard (confirmation required)

## Browser Compatibility

Works on all modern browsers (Chrome, Firefox, Safari, Edge)

## Tech Stack

- HTML5
- CSS3 (Grid & Flexbox)
- Vanilla JavaScript
- PDF.js (for PDF rendering)
- Local Storage API
